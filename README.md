# Зоны из АИП России — в формате OpenAir

Здесь собирается файл запретных зон, зон ограничения полётов и опасных зон
для [Ivan's Skyjournal](https://t.me/IvanSkyJournal) — приложения-бортжурнала
для амфибии.

**Готовый файл:**
[zones-russia-aip.txt](https://gist.githubusercontent.com/M1hairu/bff354241f7b6318c30b8973928958c4/raw/zones-russia-aip.txt)
· 2659 зон · формат OpenAir · обновляется раз в неделю

## Откуда данные

АИП России публикуется открыто: [ЦАИ ГА](https://www.caica.ru), разделами
в PDF. Раздел **ENR 5.1** содержит координаты зон прямо в тексте. Скрипт
`aip_zones.py` качает его, разбирает и переводит в OpenAir — формат, который
читают планерные и парапланерные программы.

Раз в неделю это делает GitHub, компьютер при этом может быть выключен.

## Что важно знать

**Это пересказ документа, а не сам документ.** Файл собран разбором PDF.
Для навигации не годится — сверяйтесь с АИП.

**Диспетчерских зон (ENR 2) здесь нет, и это решение, а не недоделка.**
Их таблица в PDF не режется надёжно: перемешаны алфавиты, часть зон описана
ссылками на другие секторы, часть — вырезанными дырками. Дважды собранный
результат дважды оказался неверным — сектор Сыктывкара накрывал Петербург,
аэродром оказывался вне собственной зоны. Ложная граница на карте хуже
её отсутствия, потому что по ней принимают решения.

**Два знака перед кодом зоны:**

- `~ULR38` — край срезан прямой: в АИП граница описана словами «далее
  по государственной границе», а точек этой линии в документе нет. Таких 12.
- `=URD116` — зона действует в несколько ярусов по высоте, нанесён нижний.
  Таких 8.

## Собрать самому

```bash
sudo apt install poppler-utils     # нужен pdftotext
python3 aip_zones.py --out zones.txt
python3 aip_zones.py --out ул.txt --fir UL    # только Северо-Запад
```

## Лицензия

Скрипт — общественное достояние, берите как есть. Данные принадлежат
их источнику: АИП России, ЦАИ ГА.
